## ⚙️ Installation

### Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
cd mentee
```

### Install dependencies

```bash
cd client
npm install

cd ../server
npm install
```

### Run the project

Start the backend:

```bash
cd server
npm start
```

Start the frontend in another terminal:

```bash
cd client
npm run dev
```
